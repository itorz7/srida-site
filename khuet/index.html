Srida Khuet LLM ภาษาไทย ที่รันในองค์กรของคุณ

คึด = คิด ภาษาอีสาน

Srida Khuet อ่านเอกสาร ตอบคำถาม และช่วยเขียนงานภาษาไทยให้คุณ ตัวระบบทำงานบนเครื่องหรือเซิร์ฟเวอร์ขององค์กรคุณเอง เอกสารจึงไม่ต้องอัปโหลดขึ้นคลาวด์ของใคร

คุยกับทีมงานรู้จัก Srida Khuet

Srida Khuet ใช้ทำอะไรได้บ้าง

  • ถามตอบจากเอกสารองค์กร

    ต่อ Srida Khuet เข้ากับคู่มือ ระเบียบ และเอกสารภายใน (วิธีที่เรียกกันว่า RAG) พนักงานถามเป็นภาษาไทยได้เลย คำตอบบอกด้วยว่ามาจากเอกสารไหน จะได้เปิดเช็กเองได้

  • สรุปรายงานและบันทึกประชุม

    ย่อเอกสารยาว ๆ ให้เหลือแต่ประเด็นสำคัญ หรือดึงรายการงานที่ต้องทำต่อออกมาให้ อ่านสรุปก่อน แล้วค่อยเปิดฉบับเต็มเฉพาะส่วนที่ต้องใช้

  • ร่างหนังสือและอีเมล

    ร่างหนังสือ อีเมล และข้อความตอบลูกค้าตามรูปแบบขององค์กรคุณ ได้ร่างแรกมาก่อน แล้วให้คนตรวจทานก่อนส่งทุกครั้ง

  • จัดหมวดและดึงข้อมูล

    มีข้อความกองโต เช่น ความเห็นของลูกค้า ให้ระบบอ่านแล้วจัดหมวดหมู่ หรือดึงข้อมูลที่ต้องการออกมาเป็นตาราง

  • เป็น API ให้ระบบเดิม

    เปิด Srida Khuet เป็น API ภายในองค์กร ระบบที่คุณใช้อยู่แล้วก็เรียกใช้ได้

  • ทำงานต่อจาก AI ด้านอื่น

    รับข้อความจากการถอดเสียงหรือ OCR มาสรุปต่อได้ ทุกขั้นตอนอยู่ในเครื่องเดียวกัน

Srida Khuet คือระบบแบบไหน

พูดง่าย ๆ คือผู้ช่วยที่อ่านและเขียนภาษาไทยได้ แต่ตัวระบบอยู่ในเครื่องขององค์กรคุณ ไม่ได้อยู่บนคลาวด์ของใคร เราเป็นคนติดตั้ง ทดสอบ และดูแลต่อให้

  • อยู่ในเครื่องของคุณ ไม่ต้องต่ออินเทอร์เน็ต

    คำถามที่พิมพ์ เอกสารที่แนบ และคำตอบที่ได้ ประมวลผลบนเครื่องหรือเซิร์ฟเวอร์ขององค์กร ติดตั้งเสร็จแล้วใช้ในเครือข่ายภายในได้เลย อินเทอร์เน็ตล่ม งานก็ยังเดิน

  • ลองกับเอกสารจริงของคุณก่อน

    เราไม่เดาว่าแบบไหนจะเหมาะ เราเอาตัวอย่างเอกสารและคำถามจริงของคุณมาทดสอบ ดูผลด้วยกัน แล้วค่อยเลือกวิธีตั้งค่าที่เข้ากับงาน จากนั้นจึงติดตั้งและสอนทีมของคุณใช้

  • ข้อมูล สิทธิ์ และบันทึก คุณคุมเอง

    ใครเข้าใช้ได้ ประวัติการสนทนาเก็บนานเท่าไร องค์กรของคุณเป็นคนกำหนด บันทึกการใช้งานก็เก็บอยู่ในเครื่องของคุณ ไม่ได้ไปอยู่กับผู้ให้บริการรายไหน

ถ้าใช้แชต AI บนคลาวด์ อะไรออกจากองค์กรไปบ้าง

  • ทุกข้อความที่พิมพ์ ทุกไฟล์ที่แนบคำถาม เอกสาร สัญญา ข้อมูลลูกค้า ป้อนอะไรเข้าไป สิ่งนั้นก็ถูกส่งไปประมวลผลบนเซิร์ฟเวอร์ของผู้ให้บริการ

  • ประวัติการสนทนาผู้ให้บริการเก็บบทสนทนาไว้ตามนโยบายของเขาเอง บริการสำหรับบุคคลทั่วไปบางรายระบุว่าอาจนำเนื้อหาไปฝึกโมเดล เว้นแต่ผู้ใช้จะปิดการตั้งค่า1

  • สายตาของคนนอกบางบริการมีผู้ตรวจทานอ่านบทสนทนาบางส่วน และบอกผู้ใช้เองว่าอย่าป้อนข้อมูลลับ2

ถ้าใช้ Srida Khuet

Srida Khuet ทำงานบนเครื่องขององค์กรคุณ ข้อความ ไฟล์ และประวัติการสนทนาอยู่ในเครือข่ายภายใน จะเก็บนานเท่าไรและใครเข้าถึงได้ คุณกำหนดเอง

คุยเรื่องติดตั้งในองค์กรของคุณ

ให้ Srida ติดตั้งให้ เริ่มกันแบบนี้

  1. 1

    คุยกันก่อน

    เล่าให้ฟังว่าอยากให้ AI ช่วยงานอะไร มีตัวอย่างข้อมูลมาด้วยยิ่งดี เช่น ไฟล์เสียงหรือเอกสาร

  2. 2

    ลองกับข้อมูลจริง

    เราเอาระบบมาลองกับตัวอย่างของคุณ แล้วนั่งดูผลด้วยกัน พอใจแล้วค่อยไปต่อ

  3. 3

    ติดตั้งในองค์กร

    ลงบนเครื่องหรือเซิร์ฟเวอร์ขององค์กร ตั้งค่าสิทธิ์ แล้วเชื่อมกับระบบที่ใช้อยู่

  4. 4

    สอนทีม แล้วดูแลกันต่อ

    อบรมคนใช้งาน ส่งมอบคู่มือ และช่วยอัปเดตระบบเมื่อมีรุ่นใหม่

คำถามที่พบบ่อยเรื่อง LLM ภาษาไทย

Local AI คืออะไร อ่านคู่มือฉบับเข้าใจง่าย

วิธีวางระบบ AI ในองค์กรทีละขั้น

LLM ภาษาไทยตัวไหนดีที่สุด

ตอบตรง ๆ ว่าไม่มีแบบไหนดีที่สุดสำหรับทุกงาน ผลขึ้นกับลักษณะงาน เอกสารของคุณ และเครื่องที่มี เราจึงเอาเอกสารและคำถามจริงของคุณมาทดสอบก่อน แล้วค่อยตั้งค่า Srida Khuet ให้เข้ากับงานนั้น

ใช้ LLM ในเครื่องกับเอกสารลับได้ไหม

ได้ และนี่คือข้อดีข้อใหญ่ของการรันในเครื่อง เอกสารและคำถามประมวลผลอยู่บนเครื่องขององค์กรคุณ ไม่ได้ส่งไปที่ไหน สิ่งที่ต้องทำเพิ่มคือตั้งสิทธิ์การเข้าถึงให้เหมาะ ซึ่งเราช่วยตั้งให้ตอนติดตั้ง

ต้องมีการ์ดจอไหม

ไม่เสมอไป งานเบาที่ใช้กันไม่กี่คน รันบนคอมพิวเตอร์ที่ไม่มีการ์ดจอได้ แต่จะตอบช้ากว่า ถ้ามีคนใช้พร้อมกันหลายคนหรืองานหนักขึ้น ควรมีการ์ดจอ บอกเราว่ามีเครื่องอะไรอยู่ เราทดสอบแล้วบอกตรง ๆ ว่าพอหรือต้องเพิ่ม

Srida Khuet ตอบผิดได้ไหม

ได้ LLM ทุกระบบตอบผิดได้ และบางครั้งผิดแบบมั่นใจด้วย คำตอบที่มาจากเอกสารองค์กรจึงบอกที่มาว่ามาจากเอกสารไหน ให้คุณเปิดเช็กเองได้ ส่วนงานสำคัญอย่างหนังสือที่จะส่งออก ให้คนตรวจก่อนทุกครั้ง

ต่อกับระบบที่องค์กรใช้อยู่ได้ไหม

ได้ เราเปิด Srida Khuet เป็น API ภายในองค์กร ระบบที่คุณใช้อยู่แล้วเรียกใช้ได้ และตอนติดตั้งเราช่วยเชื่อมให้ จะรับข้อความจากการถอดเสียงหรือ OCR มาสรุปต่อก็ได้ ทุกขั้นตอนอยู่ในเครื่องเดียวกัน
